# 커피 한 판

한 대의 스마트폰을 돌려가며 2~6명이 약 1분 안에 즐기는 간단한 내기 게임 모음입니다.

**플레이:** https://coffee-break-games.uclick-ljw.chatgpt.site

## 게임 목록

1. **얼음깨기** — 룰렛이 정한 색의 얼음을 깨면서 펭귄을 떨어뜨리지 않는 게임
2. **구슬 타워** — 타워의 막대를 제거하고 떨어진 구슬을 가장 적게 모으는 게임
3. **툭 떨어뜨려** — 돌기를 배치한 핀볼 게임판에서 구슬을 쏴 점수를 겨루는 게임
4. **긁어봐!** — 스크래치 복권을 긁어 커피나 밥을 살 사람을 정하는 게임
5. **멈춰!** — 보이는 시간 또는 감각만으로 목표 시간에 가장 가깝게 멈추는 게임
6. **완벽한 곡선** — 제시된 곡선을 기억하고 한 번에 가장 비슷하게 그리는 게임
7. **아슬아슬 트레이** — 시소 쟁반에 물건을 번갈아 쌓고 떨어뜨린 사람이 지는 게임
8. **말랑말랑 대탈출** — 동물을 움직여 장애물을 피하고 가장 오래 살아남는 게임
9. **아슬아슬 착륙** — 추력과 방향을 조절해 가장 부드럽고 정확하게 착륙하는 게임
10. **한 번에 주차** — 차를 한 번 출발시켜 조향과 제동만으로 주차칸에 정확히 멈추는 게임
11. **반으로 쓱** — 서로 다른 비대칭 물체를 한 줄로 잘라 50:50에 가장 가깝게 나누는 게임
12. **그림자 도둑** — 3D 조형물을 돌려 목표 그림자와 가장 정확하게 겹치는 게임
13. **길을 바꿔라** — 화살표 타일을 돌려 경비원을 피하고 도둑의 탈출로를 완성하는 게임

`멈춰!`에는 시간을 보면서 맞추는 방식과 시간을 숨기고 감으로 맞추는 방식이 들어 있습니다.
