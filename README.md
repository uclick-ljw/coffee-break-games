# 커피 한 판

한 대의 스마트폰을 돌려가며 2~6명이 즐기는 간단한 내기 게임 23종입니다. 대부분 약 1분, 개인별 퍼즐은 인원에 따라 더 길어집니다. 첫 화면에서 직접 고르거나 랜덤으로 뽑을 수 있고, 게임을 시작하기 전에 목표와 조작법을 확인할 수 있습니다.

**플레이:** https://coffee-break-games.uclick-ljw.chatgpt.site

## 게임 목록

### 운과 반전

- **얼음깨기** — 룰렛이 정한 색의 얼음을 깨면서 펭귄을 지키기
- **구슬 타워** — 막대를 제거하고 떨어진 구슬을 가장 적게 모으기
- **툭 떨어뜨려** — 직접 배치한 돌기 사이로 구슬을 쏴 점수 겨루기
- **긁어봐!** — 스크래치 복권으로 커피나 밥을 살 사람 정하기
- **숫자 폭탄** — UP·DOWN으로 범위를 좁히며 폭탄 숫자 피하기
- **터질까 말까** — 풍선을 부풀리고 넘기며 터뜨린 사람 가리기

### 손끝과 순간 감각

- **멈춰!** — 보이는 시간 또는 감각만으로 목표 시간 맞히기
- **빙글 꽂아라** — 회전판의 빈틈을 노려 다트 꽂기
- **말랑말랑 대탈출** — 동물을 움직여 장애물을 오래 피하기
- **아슬아슬 착륙** — 추력과 방향을 조절해 우주선 착륙시키기
- **한 번에 주차** — 한 번의 주행으로 주차칸에 정확히 멈추기

### 눈대중과 집중

- **눈금 없이 따라라** — 기억한 목표 수위에 맞춰 물 따르기
- **완벽한 곡선** — 제시된 곡선을 기억해 한 붓으로 따라 그리기
- **반으로 쓱** — 비대칭 물체를 한 줄로 50:50에 가깝게 나누기
- **중심을 찍어라** — 비대칭 3D 물체의 무게중심 찾기
- **그림자 도둑** — 3D 조형물을 돌려 목표 그림자와 겹치기
- **컵 속 구슬** — 빠르게 섞이는 컵 속 구슬 추적하기

### 배치와 전략

- **아슬아슬 트레이** — 시소 쟁반에 물건을 쌓고 떨어뜨리지 않기
- **길을 바꿔라** — 방향 타일을 돌려 도둑의 탈출로 만들기
- **도시락 빈틈없이** — 음식을 돌려 가장 빈틈없는 도시락 만들기
- **딱 세 번만 터뜨려** — 같은 색 블록을 딱 세 번 터뜨려 없앤 개수 겨루기
- **엉킨 선 풀어라** — 점을 끌어 선의 교차를 줄이고 완성 시간 겨루기
- **고양이 꺼내줘** — 상자를 밀어 두 마리 구출하기. 구출 수·구출에 쓴 이동 수·시간으로 순위 결정

새 퍼즐 세 게임은 참가자마다 같은 난이도의 판을 색·방향만 바꾸어 제공합니다. 다른 사람의 차례에는 화면을 보지 않는 방식이며, 기록이 같으면 공동 순위입니다. 게임 소리는 재생하지 않습니다.

## 로컬 실행

```bash
npm install
npm run dev
```
