# 1차 개선 — 판정과 공정성

2026-09-14. 로컬 반영만 진행. 배포·커밋·푸시 없음.

## 반영

- 도시락: 회전·이동·미리보기가 모두 현재 칸막이를 검사하도록 통일. 칸막이 인자를 필수로 변경해 누락 방지. 종료 후 드래그 반영 차단. 채운 면적을 기록 화면의 주 정보로 표시.
- 13개 점수형 게임: 동일한 비교 기준이면 공동 순위(1, 1, 3). 공동 최하위에서 참가 순서로 커피 담당 한 명을 정하지 않음. 모두 동점이면 모두 동점으로 안내.
- 대상: 멈춰, 다트, 동물 탈출, 착륙, 주차, 물 따르기, 곡선, 반으로 자르기, 중심, 그림자, 컵, 도시락, 길 퍼즐.
- 시간·오차 비교는 화면에서 확인할 수 있는 정밀도에 맞춤. 컵은 모두 오답일 때 선택 속도로 패자를 정하지 않음. 기존 유효한 보조 기준은 유지하고 안내에 명시.
- 길 퍼즐: 숨겨진 예시 정답 경로와의 일치도를 제거. 마지막 안전칸에서 경비원을 피해 EXIT까지 남은 최단 거리를 출발 거리와 비교한 접근률 사용. 실패끼리 접근률이 같으면 공동 순위. 성공 우선 및 성공 시 시간·회전 감점 유지.
- 숫자 폭탄: 매 차례 ‘받았어요’ 이후 6초 시작. 선택 가능한 숫자만 크게 표시. 중복 선택과 마감 후 선택 방지.
- 블랙홀: 일시정지 중 판을 완전히 가리고 입력 차단 유지. 재개 시 판 복원.
- 컵의 마지막 라운드 문구, 물 따르기의 평균 오차 표시, 실제 주차 조작 설명 보완.
- 새 의존성 없이 기존 검사 재사용. 공통 순위 계산과 결과 안내만 공유.

## 검증

- 기존 검사 24개 + 새 `check:ranking` 1개 통과. 2~6인 동점, 공동 최하위, 표시 정밀도, 정상 승자, 입력 배열 보존 검사.
- 도시락 네 구조에서 정상/막힌 회전 검사. 길 퍼즐의 대체 경로, 경비원 우회 거리, 예시 정답 변경에 무관한 채점 검사.
- 타입 검사, 린트, 빌드 통과. 빌드에는 500 kB 이상 청크 경고가 남아 있음.
- 로컬 모바일 크기(390×844) 브라우저에서 아래를 직접 확인.
  - 멈춰: 2인 모두 9.99초, 오차 6.74초 → 공동 1위, 한 사람만 패자로 지목하지 않음.
  - 주차: 6인 모두 0점으로 두 번 완주 → 모두 공동 1위. 여섯 이름의 줄바꿈도 확인.
  - 도시락: 오른쪽 두 칸에서 정상 회전·82점 제출·2인 최종 순위. 계단 네 칸에서 계란말이의 칸막이 관통 회전 거부. 정상 재이동 및 잘못된 재배치 거부.
  - 숫자 폭탄: 6초 이상 인계 대기 후 온전한 6초 시작, 50 선택 후 다음 참가자 준비, 범위 축소·큰 버튼, 시간 초과·재시작 확인.
  - 길 퍼즐: 실패 시 접근률 33%·출구까지 4칸. 다음 참가자는 보이는 타일을 분석해 실제 4회 회전·탈출 성공 71점. 성공 우선 최종 순위 확인.
  - 블랙홀: 연습에서 남은 4초를 유지하는 정지/재개와 완전 가림. 연습 종료 후 2인 본게임 20점/0점의 최종 순위까지 확인.
  - 착륙: 실제 점화·비행·첫 참가자 충돌 0점까지 확인. 이번 브라우저 검증에서 2인 최종 결과까지 확인한 것으로 세지 않음.
- 순위 처리를 바꾼 13개 게임의 시작 화면 로딩·참가 인원 설정 확인. 수집된 브라우저 오류 없음.

## 이번에 바꾸지 않은 것

구슬 타워의 진행 밀도, 물리 수치, 난이도, 고정 퍼즐의 새 문제 생성, 연습 모드 확대, 공통 참가자 설정은 후속 항목이다. 정상 동작 중인 게임 감각과 판정 수정을 한꺼번에 바꾸지 않았다.
